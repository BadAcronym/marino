# The idea:
- Playnite-like launcher, but with more media support for stuff like:
    - movies and other types of video
    - creative and professional software
    - books
    - basically anything you might want to launch from a global shortcut, rofi-like
      (just add plain dmenu integration?)
- cross-platform
- performant but available (Software / OpenGL)

# MVP functionality:
- global shortcut launcher & search (fd/rg? or make own?)
- custom adder of executables with metadata for each entry
- data management, custom file format
- time tracker
- state selector (completed / beaten / in progress / playing / NG+ / custom),
  customizeable
